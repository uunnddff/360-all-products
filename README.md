# Актион 360 — все продукты

Адаптивная продуктовая витрина Актион 360, собранная по макету Figma и наполненная контентом из продуктовой таблицы.

## Запуск

```bash
npm install
npm run dev
```

Перед запуском карточки автоматически обновляются из Google-таблицы. Каждый лист соответствует направлению, каждая заполненная строка — продукту.

Обновить только данные:

```bash
npm run sync:catalog
```

## Сборка

```bash
npm run build
```

При сборке данные также обновляются автоматически. Последняя успешная выгрузка хранится в `src/catalog.generated.json`, поэтому локальная версия продолжит работать, если Google Sheets временно недоступен.
